**Edge AI brings machine intelligence closer to the devices creating the data — enabling responsive, resilient, and privacy-aware intelligent experiences without requiring every inference request to travel to the cloud.**

This prototype demonstrates real browser-based local AI inference, interactive Edge AI architecture concepts, and a practical Edge + Cloud framework. Built for developers, researchers, and technology enthusiasts who want to understand and explore the future of distributed intelligence.

---

## ✨ Features

![Live Demo](https://images.unsplash.com/photo-1485827404703-89b55fcc595e?w=600&h=400&fit=crop&q=80)

### 🎯 Real Local AI Inference
- **Live object detection** using TensorFlow.js + COCO-SSD
- **Real-time metrics**: objects detected, frames analyzed, inference time, FPS
- **100% browser-based** — no data leaves your device
- **Privacy-preserving** — camera feeds are never transmitted

### 🏗️ Interactive Architecture
- **Edge AI Pipeline**: From sensor to intelligence
- **Edge + Cloud Framework**: Understanding hybrid architectures
- **Model Lifecycle**: From training to deployment
- **Technology Stack Explorer**: From application to sensors

### 📊 Smart Decision Tools
- **Edge vs Cloud comparison** with real-world scenarios
- **Architecture Decision Tool** with 5 key questions
- **Device Explorer** across personal, mobility, industrial, and healthcare

### 🎨 Beautiful & Responsive
- **Premium dark/light themes** with smooth transitions
- **Fully responsive** from 320px to 1920px
- **Accessibility-first** with ARIA labels and keyboard navigation
- **Reduced motion support** for accessibility

## 🚀 Quick Start

### Prerequisites
- Modern web browser (Chrome, Firefox, Safari, Edge)
- Webcam for live demo
- Internet connection for CDN resources

### Installation

```bash
# Clone the repository
git clone https://github.com/theinsidecoder/edge-ai-prototype.git

# Navigate to project
cd edge-ai-prototype

# Open in browser
open index.html
No build process required! The entire application runs as static HTML with CDN-loaded libraries.

📐 Architecture
text
DATA SOURCE → SENSOR → EDGE DEVICE → PREPROCESSING → AI MODEL → INFERENCE → DECISION → ACTION
Edge vs Cloud
Aspect	Edge AI	Cloud AI
Latency	Low (local processing)	Higher (round-trip)
Privacy	Data stays local	Data transmitted
Offline	Works offline	Requires connectivity
Compute	Limited by device	Elastic scalability
Models	Optimized, smaller	Large, complex
